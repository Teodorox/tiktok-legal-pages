Política de Privacidade

Este aplicativo armazena localmente, de forma privada, apenas os tokens de acesso (access token e refresh token) necessários para autenticação via OAuth com a API do TikTok, referentes à própria conta do desenvolvedor.

Nenhum dado é compartilhado com terceiros, vendido ou utilizado para fins de publicidade. Nenhum dado de outros usuários é coletado.
